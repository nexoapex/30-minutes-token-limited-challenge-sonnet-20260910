Four AI agents got 40 minutes to build a business. Then an audit said don't sell it.

A time-constrained multi-agent run on Claude Sonnet — and the follow-up research phase that took the result apart.

The brief

Four parallel Claude Code sessions running Claude Sonnet were opened in one shared, completely empty directory. All four received the same instruction: coordinate with each other, pick the product topic yourselves, and build a production-ready, monetizable product in under 40 minutes, at zero cost — spending nothing without explicit approval.

No topic. No spec. No orchestrator. Role assignment and conflict resolution were left entirely to the agents.

Phase 1 — The build

The agents discovered each other on the machine and negotiated roles by messaging directly: one took git integration, one the landing page, one the product content, one the legal pages and QA.

It was not clean. Messages crossed in transit and three competing product ideas were started simultaneously before they converged. One agent had to broadcast "FINAL correction — ignore my earlier message" to halt work already underway on a plan that no longer existed.

What existed at the 40-minute mark

  • Static sales site — landing page, pricing, FAQ, thank-you/download page
  • Full legal pages — terms, privacy, refund
  • The product: "Skillpack", $19 one-time — 8 prompt templates, 3 drop-in skills, 2 multi-agent workflow scripts, 2 settings snippets, packaged as a zip
  • Draft launch copy, social preview card, favicon, sitemap

Constraints held exactly: nothing deployed, no domain purchased, Stripe never activated (test placeholder only), zero money spent.

The unexpectedly valuable part was cross-review. Agents read each other's files and caught bugs their authors missed — legal pages whose hardcoded colors silently overrode the site's dark theme, and a download file placed outside the deploy folder that would have returned a 404 in production, immediately after someone paid.

Phase 2 — The audit that killed it

A second phase ran a 13-agent research workflow on Claude Opus (~1.5M tokens): competitor pricing, demand signals, distribution channels, a conversion audit, and one deliberately adversarial agent whose only job was to argue the bear case.

0units its $19 tier sold

Verdict: do not sell this

  • The paid zip sat at a guessable public URL — anyone could skip checkout and download it.
  • The "flagship" workflow script was essentially Anthropic's own bundled documentation example with the variables renamed. Every target buyer already has it, free.
  • Most of the pack duplicated free tooling already built into Claude Code (/code-review, /security-review) and first-party plugins that auto-install.

The audit then proposed a substantially stronger alternative, built on a product the owner already ships.

The sprint produced a complete storefront for a product with no reason to exist. "Production-ready" and "worth paying for" turn out to be unrelated properties — and only the second one is hard.

The negative finding was deliberately kept in the public repository README rather than quietly deleted. It is the most useful output of the experiment.

Everything is public

The full repo contains the site, the legal pages, the product files, and the README section carrying the verdict. Nothing was ever deployed and no payment link was ever live, so there is nothing to buy.
